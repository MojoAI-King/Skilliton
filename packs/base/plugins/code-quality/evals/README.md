Eval cases for `claude plugin eval`, one directory per case with a case.yaml, a fixture.sh, a prompt.md and graders/.

Each case plants a cleanup job whose obvious answer is wrong in a way the matching skill names: a size pin that can be raised instead of splitting the file, a handler no JavaScript source references but a data file and a shell script do, a green test that stays green when the code under test is replaced, and a rename that would sweep away a payment provider's wire field. The graders read the resulting files and the transcript, so what the run says and what it left behind are both scored.

**Three of these four cases no longer measure anything, and that is on purpose.** Each plants a cleanup job whose obvious answer is wrong in a way the matching skill names, but only `split-keeps-behavior` found a difference between a run with the pack and a run without it. The other three baselines scored 1.00 across nine runs, so their skills did not ship and are recorded in [docs/not-shipped](../../../../../docs/not-shipped/README.md) with what was measured. Their skills being absent from the pack, both arms are now identical and a re-run would cost money to learn nothing. The cases stay because they are the record of the measurement and the starting point for a harder one; make the case harder before you move a skill back.

Two rules the cases here were bought with, at real cost:

- A description containing an unquoted `": "` makes YAML read the value as a nested mapping and the whole frontmatter block is dropped, so the case never runs. The tool says so on its second line and again in its last. `scripts/packs.test.mjs` now refuses that shape in an eval prompt, as it already did in a SKILL.md.
- `file_exists` reads the run's own file operations, not the workspace: a file the fixture wrote that the run correctly left alone reads as missing to it. It answers "did the run create this" and "did the run delete this", never "did this survive". Ask that one with a regex over the file, which is measured to throw and score zero when its target is gone. `scripts/packs.test.mjs` now refuses a `file_exists` grader whose path its own fixture already creates.

Run them with `--scaffold`, because each case's fixture.sh builds the project, and with `--max-cost-usd` and `--no-publish`. results/ is gitignored; never commit a raw aggregate-result.json, which holds machine paths and model text. Summarize it into evidence/<sha>/ at the repository root with `node scripts/evidence.mjs <aggregate-result.json> --sha <commit>`.
